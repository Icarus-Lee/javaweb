# javaweb 教程目录（64 篇）

> **给谁读**：会 C/C++/Python 的学习者，Java/JS 零基础起步、速通进入全栈实战。
> **两座城主线**：票务大厅（火车购票 = 同步高并发 + 锁与库存）与外卖后厨（外卖平台 = 异步事件 + 缓存）——五个框架结合着讲，每个框架都出现在真实的服务链路里。
> 六件套齐全：动手验证（真实 curl/redis-cli/实测输出）→ 思考题 → 练习题 → **完整参考答案** → 本节小结 → 下一站。
> 一切可跑：`bash infra/start-all.sh && bash infra/smoke.sh`（22 断言全绿）。
