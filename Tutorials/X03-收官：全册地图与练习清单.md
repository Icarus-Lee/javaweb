## 4. 附：一页纸"速查卡"（建议打印）

把全册压缩到一页，各段一句"骨架代码"：

```
【零起点】 bash infra/start-all.sh && bash infra/smoke.sh        # 23/23 是全册生命线
【A Java】 record Point(int x,int y){} / stream().filter().map() / try-with-resources
【B 前端】 const x = ref(0); watch(x, ...) / axios 拦截器塞 token
【S Spring】 @Service 注入 / @Transactional / @ControllerAdvice / @Scheduled / MockMvc
【R Redis】 DECR 原子扣减 / setIfAbsent 抢锁 + finally 还锁 / TTL 抖动防雪崩
【K Kafka】 send(topic, key, payload) / @KafkaListener(groupId) / offset=书签 LAG=欠账
【N Nginx】 proxy_pass 反代 / try_files SPA 兜底 / nginx -t 先验后 reload
【T 火车】  锁→扣→插→发④步 / closeExpired 15 行 / 审计第二账本
【W 外卖】  LEGAL_NEXT 白名单 / key=orderNo 分区有序 / 空哨兵防穿透 / 补偿=反向操作
【X 收官】  冷启动有顺序 / BCrypt 故意慢 / 默认拒绝(fail-safe)无处不在
```

三条全册最重要的"默认值"（答得出这三条，说明你抓到了骨架）：
1. **默认拒绝**：白名单、拦截器、参数校验——没说放行的都是拒绝；
2. **宁重勿丢**：at-least-once + 幂等，而不是恰好一次的豪赌；
3. **真相源唯一**：每份数据问一次"谁才是真的"——订单在 H2、余票在 Redis、菜单在 H2（Redis 只是缓存）。
