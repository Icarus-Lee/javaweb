```text
$ cd Tutorials
$ ls *.md | grep -v README | wc -l        → 64
$ ls *.md | grep -v README | grep -v ^README | grep -v E...
# 实核三遍：

# ③ 工程实录标签：ls W0*.md X0*.md 后 grep -l "工程实录" 六 + 三 = 9 篇全中 ✓
```

**清理修补残留**：V3 改写过程中最容易多出来的残留是——重复小节标题（如"本节小结"在文件尾多一份）、章节号断档（上一站写 12 下一站 9）、"实用性附录"与正文重复的段落。收官自查命令（并已在改版中逐个清零）：

```text
$ grep -c "^## " W0*.md X0*.md          # 每篇 11 段左右、双标题=残留
$ grep -n "^## [0-9]" W0*.md X0*.md     # 章节号连读一遍
$ grep -c "工程实录" W0*.md X0*.md      # 9 篇应全部 ≥1
```

小结：**地图的权威不来自"写在最后一章"，而来自和磁盘逐行对过账**——这也是整册工程伦理的最后一次示范。
